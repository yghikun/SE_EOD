# Domain Evaluation Split v0.3

The split unit is an operation family, not a Bug ID or relation projection.

| Family | Role | Decision |
|---|---|---|
| runtime-relocation-merge | DEVELOPMENT | forms RRAS; same-family patches are validation only |
| btrfs-device-shrink | DEVELOPMENT | forms DSSA; fixed success/failure are paired replay |
| ext4/XFS/F2FS capacity paths | OUTSIDE_CATALOG | non-equivalent objects and equations |

Both frozen protocols have one family and no held-out family. Therefore
`freeze_eligible=true` means narrow protocol evidence is closed, while
`generalization_eligible=false` means no independent-family claim is allowed.
